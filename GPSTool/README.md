# GPS 轨迹视频叠加工具

把手表 / 手机记录的运动轨迹（**GPX / FIT / TCX / XML**）与拍摄的视频做时间对齐，
把实时速度、配速、里程、海拔、坡度、心率、踏频、功率、时间、位置等数据以仪表盘形式
烧录到画面中，并附路线轨迹小地图（已骑路段实时变绿、脉冲点标注当前位置）。

## 快速开始

**方式一（推荐交付他人）：免安装绿色版**
打包好的可执行程序位于 `..\dist\GPSTool\`，把整个 `GPSTool` 文件夹复制到任意
Windows 10/11 64 位电脑，双击其中的 `GPSTool.exe` 即可（无需安装任何环境，
功能与源码版完全一致，详见同目录 `使用说明.html`）。
重新打包：修改源码后双击 `重新打包.bat`（构建环境在 `..\work\build_venv`）。

**方式二（本机开发调试）：源码运行**

双击 **`启动工具.vbs`**（无控制台黑框），然后：

1. **运动信息与视频**：添加轨迹文件（**可导入多条**，列表显示 轨迹文件 / 距离 / 日期 /
   起点时间 / 终点时间 / 时长，选中哪条就用哪条）；添加视频、**添加文件夹**（整目录导入）；
   视频起点时间自动识别（文件名拍摄时间 → 容器时间反推），双击『起点时间』改绝对时间、
   双击『起点时间调整』按秒微调；拍摄时间超出轨迹范围的行会**红色高亮**提醒。
   点「**批量调整时间**」可给列表里**全部**视频统一加减一个时间偏移（分 + 秒，可选推后/提前）；
   它**只改偏移**，不会把所有视频改成同一个起点时刻，各视频之间的时间差保持不变。
2. **信息显示设置**：选仪表盘样式、主色调；数值面板与轨迹图的**透明度合并为一行滑杆**、
   独立调节；**位置与大小都在预览图上拖动**（拖主体移动、按住任一个角拖动＝等比缩放、
   按住某条边拖动＝只移动该边；鼠标靠近时元素显示虚线框，全景图与放大图各自独立，即时流畅刷新）；
   **信息布局可保存命名方案**，随时调用；按**运动形式**一键套用要显示的数值。
   面板排版：第一行 日期 / 时间，最后一行 地理位置（独占整行）；
   仪表盘上显示的指标（速度或配速）不再在面板中重复。
3. **输出与执行**：选输出目录、输出分辨率与画质（高 / 中 / 低），点「开始生成」。
   界面会显示预计输出时间，可随时停止；勾选**「输出完成后关机」**可在全部任务完成后
   自动关机（60 秒倒计时，可取消）。生成过程中 core 引擎的进度日志（HUD 帧速率、
   ffmpeg 合成、输出体积）会实时显示在界面日志区。

`启动工具.vbs` 双击即可启动（不弹控制台黑框）；若启动异常，可改用
**`诊断启动（会显示黑框）.bat`** 启动，它会把运行信息显示在控制台里便于排查。
也可以直接把轨迹文件和视频**拖到启动器图标上**启动。

## 功能说明

- **时间对齐**：视频第 t 秒 = 拍摄起点时刻 + t，按轨迹逐帧插值，精度 ±1~2 秒
  （取决于手表与手机时钟偏差）。
- **数据来源**：定位 / 海拔 / 速度 / 里程 / 坡度 / 时间由轨迹计算；心率 / 踏频 / 步频 /
  功率取自 FIT、TCX 等文件内的传感器通道（无数据的项自动禁用，不会编造数值）。
- **仪表盘样式**：简洁、经典、圆形仪表盘、光环仪表、半环仪表、点环仪表、横条仪表；
  **运动形式选「跑步」时仪表盘自动显示配速，其余显示速度**（面板中不再重复该项）。
- **面板排版**：第一行 日期 / 时间；其余数值按 总里程、当前里程、用时、速度/配速、
  步频、心率、功率、踏频…… 顺序排列；地理位置固定独占最后一行。
- **轨迹图**：全景轨迹小地图（**透明底**，已骑路段实时变色、脉冲点标注当前位置）+
  可选**放大轨迹图**（圆形透明底，显示当前位置前方 500 m / 后方 100 m，
  行进方向永远朝上）。两者透明度共用，**位置与大小（含长宽独立缩放）互相独立**。
- **显示位置与大小**：全部在预览图上拖动完成（移动拖主体、按住任一个角拖动＝等比缩放、
  按住某条边拖动＝只移动该边）；鼠标靠近或拖动时显示的**虚线框＝这一组实际看得见的
  内容边界**（面板连半透明底框一起算），所以框和画面里的字是贴合的，不会虚大一圈。
  按在哪一组上就操作哪一组，不会被旁边组件的角/边判定带抢走；预览与成片共用同一套
  「设计像素 → 成片像素」换算，拖动所见即输出所得。可保存为命名布局方案（layouts.json）
  随时调用。
- **自动参数**：表盘量程按轨迹速度自动设定（99.5 分位，抗 GPS 跳点）；
  刷新率按视频时长自动设定（≤4 分钟 10fps，≤10 分钟 6fps，更长 4fps）。
- **输出**：输出分辨率可选 原始分辨率 / 4K / 2K / 1080p / 720p；
  画质 高(CRF20/fast) / 中(CRF23/veryfast) / 低(CRF27/ultrafast)；
  HUD 帧多进程并行渲染；输出为 H.264 MP4（兼容主流播放与剪辑软件）。

## 目录结构

```
GPSTool/
├── 启动工具.vbs          双击启动（无黑框）
├── 诊断启动（会显示黑框）.bat   排查用启动器
├── gps_overlay_gui.py    图形界面
├── gps_overlay_core.py   核心引擎（也可命令行单独使用）
├── python/               内置便携版 Python 3.12（含 Pillow / tkinter）
├── tools/                ffmpeg / ffprobe（缺失时自动下载）
└── settings.json         上次的配置（自动保存 / 恢复）
```

## 命令行用法（可选）

```
python gps_overlay_core.py --track 骑行.fit --video a.mp4 b.mp4 ^
       --start "2026-09-14 07:51:45" --outdir out --height 1080 ^
       --style 圆形仪表盘 --template 骑行 --panel-pos 下 --map-pos 右上角 --quality 中
```

`--style`：简洁 / 经典 / 圆形仪表盘 / 光环仪表 / 半环仪表 / 点环仪表 / 横条仪表；
`--fields` 可逗号分隔指定字段 id
（date,time,geo,total,dist,elapsed,speed,ele,slope,pace,step,hr,cadence,power）。

## 提示

- 输出高度选「原始分辨率」时效果最佳；低于 1080p 时 HUD 会等比缩小、文字变小。
- 整个 `GPSTool` 文件夹是自包含的，拷贝到其他 Windows 电脑无需安装任何环境。
